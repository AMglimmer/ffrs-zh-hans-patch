# FFRS 简体中文术语修订补丁 0.3.1

以 FF14 国服译名为优先规范，修订 Steam 正式版中的 175 条简体中文文本，其他 26,550 条保持原文。繁体中文及其他语言不变。

这是纯译名包：不包含宽屏 ASI/DLL，不修改存档、不解锁角色或 DLC、不注入游戏进程。

## 使用

1. 完整解压 ZIP 到游戏目录以外的可写文件夹。
2. 退出游戏，双击“一键安装.cmd”（Install.cmd 也可）。
3. 自动寻找 Steam 正式版；找不到时选择正式版根目录或 FFRS/Binaries/Win64。
4. 从 Steam 正常启动，选择简体中文。无需管理员权限或额外运行环境。

只支持已核对的 Steam build 24250053 / Windows x64；安装器核对 EXE 和补丁文件哈希，拒绝 Demo、未知版本及同名冲突文件。其他修改简体 Game.locres 的翻译 MOD 可能覆盖同一资源。

## 主要变化

- 火光→核爆、百万火光→百万核爆；莫古利→莫古力。
- 卡邦库尔→宝石兽、提灯怪→冬贝利、仙人掌怪→仙人刺、小仙人掌→幼小仙人掌。
- 强行分离→粗分斩、燃烧领域→爆破领域、复原→康复、渐愈→再生、急速→加速、缓慢→减速。
- 哥布林拳→哥布林乱拳、流水吐息→水流吐息、剑之舞→剑舞、袒护→保护。
- 曼陀罗→蔓德拉、石化翼蜥→石蜥蜴、狂迷之声→错乱之声、芥末炸弹→芥末爆弹。
- Bomb 怪物“炸弹”→爆弹怪；父母全名为爆弹之父/母。
- 药品以太→以太药；以太胸甲等装备名不会误加“药”。
- Drain、Blood Drain / Leech 保留原来的“吸血”译名体系，“吸血匕首”也维持原文。敌方 Revive“再生”→苏生，与持续回血的 Regen“再生”区分。

相关技能说明、被动、状态、教程及对白同步修订。本版全部精确文本键与修改前后内容见 changes.json；不代表全游戏术语已全面审校。

## 禁用、卸载与升级

- 禁用译名.cmd / 启用译名.cmd：将三个配套文件一起禁用或启用。
- 卸载并还原.cmd / Uninstall.cmd：恢复本次安装前的版本及启用状态。若之前装过旧译名包，卸载会恢复旧包；要暂时看原译，请用“禁用译名”。
- 保留本解压目录中的 .ffrs-terminology-state.json 和 .ffrs-terminology-backups，它们是恢复依据。
- 升级请把新 ZIP 解压到新文件夹，然后使用新包安装；之后用新包的管理按钮。不要交叉使用旧整合包与新独立包的管理脚本。

只管理以下新增文件，不改原始 EXE/Pak/IoStore：
`FFRS/Content/Paks/~mods/FFRS-FlareZhHans_99_P.pak`
及同名 .utoc、.ucas。三个文件必须一起存在；仅复制 Pak 不会生效。文件名保留旧名是为了平滑升级，不代表仅修订 Flare。
