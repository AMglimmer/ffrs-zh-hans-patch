## 安装

退出正式版，双击 Install.cmd，输入 Steam 游戏根目录，例如：
`D:\SteamLibrary\steamapps\common\FINAL FANTASY RESONANCE`

正常从 Steam 启动并使用简体中文。无需编译、额外 DLL 或 FFR Modding Tools。
从 0.1.0 / 0.2.0 升级时直接运行新版 Install.cmd：会核对旧包哈希、备份到新版文件夹的 backups，并替换为合并包。游戏内仍只加载一个文本包。
新增以下独立文件及同名 .utoc / .ucas 配套文件，不修改游戏原始 EXE、Pak、存档或宽屏补丁：
`FFRS\Content\Paks\~mods\FFRS-FlareZhHans_99_P.pak`

必须将 payload 中同名的 .pak、.utoc、.ucas 三个文件一起安装到该目录；只放 Pak 不会被正式版挂载。
仅支持已核对的 Steam 正式版 build 24250053；安装器会检查 EXE 哈希。
不建议与其他修改简体 Game.locres 的翻译包同时使用，因为会覆盖同一资源。

## 卸载

退出游戏后双击 Uninstall.cmd 并输入同一游戏根目录。
也可只删除 `FFRS-FlareZhHans_99_P` 同名的 .pak、.utoc、.ucas 三个文件，不要删除游戏自己的包或其他 MOD。
卸载会移除整套术语修订。若只想退回 0.1.0，可退出游戏后将 backups 中的旧包按原文件名复制回上述目录。
