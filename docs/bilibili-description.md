# 简介草稿

给《FINAL FANTASY RESONANCE》Steam 正式版做了一个非官方简体中文术语统一补丁，以 FF14 国服译名为优先参考。

这次共修订 178 条文本：核爆、莫古力、宝石兽、冬贝利、粗分斩、爆破领域、康复、再生、加速、减速，以及对应说明、被动和部分对白。其余 26,547 条文本保持原样。

下载：https://github.com/AMglimmer/ffrs-zh-hans-patch/releases/latest
源码：https://github.com/AMglimmer/ffrs-zh-hans-patch

完整解压，退出游戏，双击“一键安装.cmd”，正常从 Steam 启动并选择简体中文。支持 Steam build 24250053 / Windows x64；其他版本会拒绝安装。可以禁用，或卸载并恢复安装前的文件。

这是纯译名 MOD：不包含宽屏 DLL/ASI，不修改存档或角色，不修改原始游戏 EXE/Pak。其他修改同一 Game.locres 的翻译 MOD 可能相互覆盖。

术语参考：https://strings.ffcafe.cn/
制作工具：repak、retoc；代码及各工具许可见项目仓库。游戏文本与素材版权归各自权利人。选择 FF14 译法是一种社区统一规范，不代表其他作品的官方译法都是错误。

录制可展示：原版/修改后的技能菜单、角色名称、一次安装与禁用恢复。既有核爆和莫古力已获实机确认；新增条目仍在持续验收，简介不要写成“所有文本和场景已穷尽验证”。
